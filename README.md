# WMSD leakage-free reanalysis package

This package contains the complete code and notebooks used for the corrected internal reanalysis of the 60-record WMSD risk-classification dataset.

## Important status

The statistical outputs are **provisional** until the number of unique human workers is confirmed. The current code treats each `Participant ID` as a separate worker because no repeated-worker mapping was supplied. If any IDs belong to the same person, grouped cross-validation must replace ordinary stratified cross-validation before results are reported.

## Package contents

- `notebooks/00_data_audit.ipynb` — validates the analysis file, class counts, prohibited predictors and duplicated bilateral RULA pairs.
- `notebooks/01_primary_nested_cv.ipynb` — runs the eight leakage-free classifiers with repeated nested stratified five-fold cross-validation and feature ablation.
- `notebooks/02_secondary_analyses.ipynb` — runs uncertainty estimates, sex-stratified evaluation and sensitivity analyses.
- `notebooks/03_results_summary.ipynb` — loads and displays the principal tables.
- `notebooks/04_computational_benchmark.ipynb` — benchmarks one frame-level file and records author-entered Kinovea/manual-processing time on the study computer.
- `notebooks/05_learning_curve.ipynb` — runs the diagnostic GBT learning-curve analysis and generates the manuscript-ready figure.
- `figures/manuscript/` — manuscript-ready 600-dpi figures, including corrected workflow diagrams, non-overlapping RULA intervals, and the learning curve.
- `figures/diagram_sources/` — editable draw.io (`.drawio`) source files for the four hand-authored workflow/design diagrams (Figures 1, 2, 4 and 5); open at [app.diagrams.net](https://app.diagrams.net) to edit and re-export. The remaining figures (3, 6–12) are generated directly from data by the `src/` scripts and have no separate diagram source.
- `verification/rula_correction/` — independent original-versus-corrected rerun summaries documenting the two `RULA_Left` corrections and their analytical impact.
- `figures/supplementary/Figure_S1_legacy_logistic_coefficients.png` — legacy exploratory coefficient matrix retained for audit but removed from the main manuscript.
- `src/generate_study_workflow_figures.py` — code for Figures 1 and 2.
- `src/generate_descriptive_figures.py` — code for Figures 6–9; Figure 6 uses the deidentified summary counts in `data/manuscript_figure_summary_counts.csv`.
- `src/generate_model_figures.py` — code for Figures 4, 5, 10 and 11.
- `src/run_learning_curve.py` — analysis and plotting code for Figure 12.
- `src/run_reanalysis.py` — exact primary analysis engine used for the supplied outputs.
- `src/run_secondary_analysis.py` — exact secondary analysis engine used for the supplied outputs.
- `data/WMSD_analysis_deidentified.xlsx` — analysis-ready dataset with names, pain indicators and `MSDs Index` removed.
- `results/primary/` and `results/secondary/` — outputs generated by the full 10-repeat run.
- `protocol/REANALYSIS_PROTOCOL.md` — protocol frozen before corrected results were inspected.
- `requirements.txt` — Python dependencies.

## Run order

Open the notebooks from the package root and run them in numerical order. The full primary run may take around 20 minutes depending on the computer. Notebook 01 defaults to the full 10 repeats; set `REPEATS = 1` only for a smoke test.

Command-line equivalents:

```bash
python src/run_reanalysis.py --data data/WMSD_analysis_deidentified.xlsx --output results/primary --repeats 10
python src/run_secondary_analysis.py --data data/WMSD_analysis_deidentified.xlsx --primary-predictions results/primary/out_of_fold_predictions.csv --output results/secondary --repeats 10
python src/run_computational_benchmark.py --frames benchmark_inputs/1001_Right_10min_scored.csv --data data/WMSD_analysis_deidentified.xlsx --output results/computational_benchmark
python src/run_learning_curve.py --data data/WMSD_analysis_deidentified.xlsx --output results/learning_curve --repeats 10
python src/generate_study_workflow_figures.py
python src/generate_descriptive_figures.py --data data/WMSD_analysis_deidentified.xlsx --summary-counts data/manuscript_figure_summary_counts.csv --output figures/manuscript
python src/generate_model_figures.py --package-root .
```

The benchmark must be run on the authors' study computer. Results produced on another computer are only a functionality check and must not be reported in the manuscript.

The learning curve is diagnostic rather than a new model-selection procedure. It uses the modal GBT configuration from the completed inner-tuning runs and evaluates fixed training fractions within the same repeated stratified five-fold outer partitions.

The diagnostic curve showed mean outer-validation balanced accuracy increasing from 0.802 at a median of 19 training records to 0.953 at 48 records, while training performance stayed near 1.00. This supports a cautious interpretation: more data improved validation performance, but overfitting risk remains.

## Leakage controls

`Name`, all nine body-region pain indicators and `MSDs Index` are absent from the analysis file. Preprocessing and hyperparameter tuning occur inside training partitions. The outcome-informed logistic-regression filtering used in the legacy workflow is not used.
