# Data-provenance notice

The supplied 60-row dataset is the same dataset used by the final RapidMiner thesis processes. All names, symptom/pain indicators and the continuous MSD Index have been removed from the packaged analysis file.

The bilateral RULA audit identified 18 exactly duplicated left/right score pairs affecting 36 records. The author stated that the videos were independently recorded and that the RULA values were independently calculated, not copied or synthetically generated. A source-file/frame-count manifest was not available.

The author also answered “No” when asked whether IDs 10001–10060 represent 60 separately recruited real workers, but the exact number of unique humans and any repeated-worker ID mapping remain unresolved. Consequently, the included results must not be described as final evidence from 60 independent participants until this is clarified. If any person appears more than once, use grouped validation with a worker identifier and revise all denominators accordingly.

The partial 30-person SEP file is an older/incomplete version and was not used to overwrite the authoritative final dataset.
